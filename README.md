# 💳 TypeScript CLI Digital Wallet

An interactive, feature-rich command-line digital wallet application built with TypeScript, Node.js (`readline`), and `tsx`. Modeled after modern fintech applications like du Pay and Remitly.

## ✨ Features
* 🔒 **PIN-Based Authentication**: Secure login access (`1234`).
* 💸 **Money Transfer**: Send funds dynamically to other users with low-balance validation.
* 📥 **Deposit Money**: Add funds directly to your wallet.
* 📱 **Mobile Recharge**: Support for local networks (**du** & **Etisalat**).
* 📜 **Transaction History**: Real-time logging of all runtime transactions.
* 🔄 **Persistent Menu Loop**: Non-blocking CLI interface for seamless user experience.
